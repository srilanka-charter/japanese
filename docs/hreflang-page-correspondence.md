# SriNowa 5言語サイト：hreflangページ対応表

公開中の5言語サイトマップを照合し、**全136 URL（日本語39、英語36、ドイツ語20、フランス語20、スペイン語21）**を、重複しない58のコンテンツグループに整理した対応表です。[1] [2] [3] [4] [5]

完全な機械可読の対応表は、同じフォルダの `hreflang-page-correspondence.csv` を使用してください。各行に、日本語・英語・ドイツ語・フランス語・スペイン語の対応パスと、hreflang設定の可否を記載しています。

## すぐに相互hreflangを設定できるページ

| コンテンツ | 日本語 | 英語 | ドイツ語 | フランス語 | スペイン語 |
|---|---|---|---|---|---|
| トップページ | `/` | `/` | `/` | `/` | `/` |
| 料金 | `/pricing` | `/price` | `/price` | `/price` | `/price` |
| FAQ | `/faq` | `/faq` | `/faq` | `/faq` | `/faq` |

上記3グループは、5言語のページが公開済みで、内容テーマも一致しています。各ページに自分自身を含む5本の相互hreflangを出力してください。

```html
<link rel="alternate" hreflang="ja" href="https://ja.srinowa.com/pricing" />
<link rel="alternate" hreflang="en" href="https://srinowa.com/price" />
<link rel="alternate" hreflang="de" href="https://de.srinowa.com/price" />
<link rel="alternate" hreflang="fr" href="https://fr.srinowa.com/price" />
<link rel="alternate" hreflang="es" href="https://es.srinowa.com/price" />
<link rel="alternate" hreflang="x-default" href="https://srinowa.com/price" />
```

## 対応表のステータス

| ステータス | グループ数 | 意味と設定方針 |
|---|---:|---|
| `ready` | 3 | 5言語すべてに公開済み。直ちに相互hreflangを設定する。 |
| `ready_after_content_check` | 1 | URLテーマは5言語で揃う。見出し・本文・意図が翻訳関係にあることを確認してから設定する。 |
| `candidate_content_review` | 7 | 類似テーマの候補。言語間で同一コンテンツと確認できるまで相互指定しない。 |
| `partial_ja_en` | 7 | 日本語と英語のみ、またはその両言語が候補として存在する。内容一致を確認できた場合のみ2言語で相互指定する。 |
| `partial_no_ja` | 10 | 日本語版が未公開。公開済みの対応言語間だけで相互指定するか、日本語版を作成するまで自己参照canonicalのみとする。 |
| `no_counterpart` | 30 | 他言語の対応ページが未公開。hreflangは追加せず、当該言語の自己参照canonicalを維持する。 |

## 内容確認後に設定できる候補

| コンテンツグループ | 対応している言語 | 確認する内容 |
|---|---|---|
| ベストシーズン | 5言語 | タイトル、対象地域、季節情報、旅行意図が翻訳関係にあること。 |
| タクシーチャーター基礎 | 5言語候補 | 日本語の基礎まとめと各言語のプライベートドライバーガイドの範囲が一致すること。 |
| 家族・グループ旅行 | 5言語候補 | 日本語ページの対象者・本文構成が各言語の家族旅行ガイドと一致すること。 |
| モデルコースまとめ | 5言語候補 | 一覧ページとして扱う旅行日数・カード構成が一致すること。 |
| 4泊5日・5泊6日・10日間のモデルコース | 5言語候補 | 日数、訪問都市、日程内容が実質的に同じであること。 |
| 料金内訳 | 日本語・英語候補 | 安値リスクを含む日本語記事と英語の料金内訳記事の検索意図・内容が一致すること。 |
| シーギリヤ、キャンディ、ヤラ、紅茶列車 | 日本語・英語候補 | それぞれの観光地ガイドが同一の旅行者意図を満たすこと。 |

内容が異なるページ同士をhreflangで結ぶと、検索エンジンが言語版として扱わない可能性があります。**URLやテーマ名が似ているだけでは設定せず、同じ検索意図を満たす翻訳・ローカライズ版である場合だけ相互指定**してください。

## 他言語版を作成する優先ページ

日本語独自ページのうち、多言語展開の優先候補は、3〜4日コース、ゴール、ヌワラエリヤ、アクティビティ、ホエールウォッチング、占星術、旅行準備、ホテル、1日チャーターです。これらは日本語版で公開済みですが、現時点では他言語版に直接対応するページがありません。

反対に、英語系サイトにのみ存在する「プラン」「安値リスク」「空港送迎」「安全性・詐欺回避」「世界遺産」などは、日本語版を新設してから5言語対応に加えるのが安全です。

## 実装ルール

1. 各相互指定グループでは、**グループ内のすべてのページが同じhreflangセットを返す**ようにします。
2. 各ページは必ず自分自身の言語を含めます。英語は `en`、ドイツ語は `de`、フランス語は `fr`、スペイン語は `es`、日本語は `ja` を使います。
3. `x-default` は、言語選択の既定ページとして英語ページに向けます。
4. `canonical` は各言語ページ自身へ設定し、別言語ページをcanonicalにしません。
5. 対応表で空欄の言語はhreflangに含めません。未翻訳ページを無理に他言語ページへ対応付けないでください。
6. CSVを更新したら `hreflang-site-audit.json` で、5サイトマップの全URLが対応表に収録されているか再確認します。
